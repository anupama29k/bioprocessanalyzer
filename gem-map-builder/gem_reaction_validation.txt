1. iYO844 (B. subtilis) — CYTBD
=====================================

  gem_map.py currently uses:  CYTBD
  BiGG API result:            NOT FOUND in iYO844

  Tested IDs:
    CYTBD       NOT FOUND
    CYTBDpp     NOT FOUND
    CYTBD2pp    NOT FOUND

  Actual terminal oxidase reactions in iYO844 (BiGG):
    CYTB_B2     Menaquinol oxidase (7:1 protons)   — menaquinol:O2 oxidoreductase
    CYTB_B3     Menaquinol oxidase (7:2 protons)   — menaquinol:O2 oxidoreductase
    CYOO3       Cytochrome c oxidase (He, 2)       — cytochrome c:O2 oxidoreductase
    CYOR3m      Cytochrome c reductase (menaquinol 7, 3 protons)

  FINDING: CYTBD does not exist in iYO844. B. subtilis uses menaquinone-based
  electron transport (not ubiquinone like E. coli). The correct terminal oxidase
  reactions are:
    - CYTB_B2 / CYTB_B3 for the cytochrome bd menaquinol oxidase (cydAB operon)
    - CYOO3 for the cytochrome c aa3-type oxidase (qoxABCD operon)

  RECOMMENDATION: Replace CYTBD with CYTB_B2 in B. subtilis map. CYTB_B2 is the
  primary terminal oxidase under aerobic growth conditions. CYOO3 is the secondary
  (cytochrome c pathway). Both are valid but CYTB_B2 is more directly analogous
  to the "CYTBD" function we're mapping (direct O2 consumption).


2. iMM904 (S. cerevisiae) — CYTBD
=====================================

  gem_map.py currently uses:  CYTBD (for DO parameter)
                              CYTBD (for O2 parameter)
  BiGG API result:            NOT FOUND in iMM904

  Tested IDs:
    CYTBD       NOT FOUND
    CYTBDpp     NOT FOUND
    CYTBD2      NOT FOUND
    CYTBDm      NOT FOUND

  Actual cytochrome c oxidase in iMM904 (BiGG):
    CYOOm       Cytochrome c oxidase, mitochondrial  — FOUND
    CYOR_u6m    Ubiquinol-6 cytochrome c reductase   — FOUND (Complex III)

  FINDING: CYTBD does not exist in iMM904. S. cerevisiae is a eukaryote and uses
  the mitochondrial electron transport chain with cytochrome c oxidase (Complex IV),
  not the bacterial cytochrome bd oxidase. The correct reaction is:
    - CYOOm = Cytochrome c oxidase, mitochondrial (Complex IV)
    - CYOR_u6m = Complex III (ubiquinol:cytochrome c reductase) — upstream

  RECOMMENDATION: Replace CYTBD with CYOOm in S. cerevisiae map. CYOOm is the
  terminal oxidase (Complex IV) that directly consumes O2. This is the eukaryotic
  equivalent of what CYTBD does in prokaryotes.

  NOTE: This is the same class of correction as Fix 1 (CYTBD -> COXE for mammalian).
  iMM904 uses "CYOOm" as the BiGG ID for Complex IV, while mammalian models use
  "COXE". Different naming conventions in different model reconstructions for the
  same biological function.


3. iMT1026v3 (P. pastoris) — AOX
=====================================

  gem_map.py currently uses:  AOX (for methanol parameter)

  BiGG API:                   MODEL NOT IN BiGG

  Source: BioModels MODEL1612130000 (iMT1026 v3 SBML file)

  Actual reaction ID in iMT1026v3:

    Name: "Alcohol oxidase"
    Compartment: peroxisome (_x suffix on metabolites)
    Species: M_o2_x + M_meoh_x -> M_h2o2_x + M_fald_x
    (O2 + methanol -> H2O2 + formaldehyde, in peroxisome)

  Other methanol pathway reactions found:
    Methanol extracellular transport      (uptake)
    Methanol peroxisomal transport        (to peroxisome)
    Formaldehyde dehydrogenase            (FLD, dissimilation)
    Formaldehyde glutathione ligase       (spontaneous)
    Formate dehydrogenase                 (FDH, CO2 release)
    Methanol exchange                     (boundary)

  Terminal oxidase in iMT1026v3:
    ca2f164e-4a5a-4935-932c-c20b2773caa6
    Name: "cytochrome c oxidase, mitochondrial"
    Also found: "Alternative oxidase" (e988953e...)

  FINDING: iMT1026v3 uses UUID-style reaction IDs (not BiGG-style short names).
  There is no clean short ID like "AOX" in the model — it uses a full UUID.
  The reaction stoichiometry confirms: O2 + methanol -> H2O2 + formaldehyde
  in the peroxisome, which is exactly what our "AOX" mapping represents.

  RECOMMENDATION: Keep "AOX" as-is in gem_map.py. This is a human-readable
  shorthand for the alcohol oxidase reaction. The actual SBML model uses UUIDs
  which are not usable as human-readable identifiers. "AOX" correctly represents
  the AOX1/AOX2 gene products and is the standard abbreviation in all P. pastoris
  literature (Cregg et al., Cos et al., Looser et al.). The reaction_type field
  already classifies it as "metabolic" which is correct.

  For the O2 parameter, gem_map.py also uses "AOX" — this is acceptable because
  the AOX reaction IS the primary O2 consumer during methanol phase. However,
  the terminal oxidase for general respiration should ideally reference the
  cytochrome c oxidase (UUID: ca2f164e...). Since UUIDs are impractical,
  "CYOOm" (BiGG convention for yeast cytochrome c oxidase) would be the best
  human-readable ID, consistent with the S. cerevisiae fix above.
