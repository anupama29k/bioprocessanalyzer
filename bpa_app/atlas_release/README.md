# Bundled Bioprocess Atlas release (snapshot)

A copy of the `release/` tables from https://github.com/anupama29k/bioprocess-atlas, used by the
Atlas page when GitHub can't be reached. The page reads the latest release from GitHub by default.

Do not edit these files here. Build a new release in the atlas repository and copy it over:

    cp ../bioprocess-atlas/release/* bpa_app/atlas_release/

Snapshot: schema v0.3, atlas commit e4ade03 (7 datasets, 146 runs, incl. CHO, Pichia and B. subtilis). The data is CC BY 4.0; credit the original studies
listed in datasets.csv.
